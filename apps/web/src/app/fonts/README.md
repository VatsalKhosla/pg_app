# Fonts kept in the repository

`inter-rupee.woff2` holds one glyph, the rupee sign (U+20B9), from Inter's variable font. It came from the Google Fonts API with `text=₹`.

Without it, the first ₹ on a page makes the browser fetch Inter's whole Latin Extended file, 85 KB, for that one character.
