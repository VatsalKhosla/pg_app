# Instructions for AI agents other than Claude Code

Antigravity, Gemini, Codex and any other agent working in this repository: the rules Claude Code follows bind you too. Claude Code reads `CLAUDE.md`; you read this file, then the files it points to.

## Read first, in this order
1. `CLAUDE.md`: what the product is, the founders' business rules, the stack and the commands.
2. `.claude/rules/frontend.md` for anything in `apps/web`, and `.claude/rules/security.md`. Read `.claude/rules/money-and-booking.md` before touching anything that shows a price, a token, a refund or a payment.
3. `apps/web/AGENTS.md`. This Next.js (16) is newer than your training data, so read its bundled docs in `apps/web/node_modules/next/dist/docs/` before using a Next.js API.
4. For the UI refresh: `docs/design/ui-refresh.md`, the brief.

## Working alongside Claude Code
- **Your own tree.** Work only in the git worktree and branch you were given (for the UI refresh, `/home/vatkho32/work/pg-ui` on branch `ui-refresh`). Never commit to `main`, push, rebase, force-push or delete branches. Claude Code reviews your branch and merges it.
- **Your own area.** Stay in `apps/web` and `docs/design/`. Don't change:
  - `apps/api`;
  - `packages/api-client`, which is generated (`make gen-client`);
  - migrations, `.github/`, `render.yaml`, the `Makefile`, Docker files;
  - `apps/web/src/proxy.ts`, `apps/web/src/lib/security/`, or the auth checks.

  If a change needs one of those, write down what and why, and ask the founder to pass it to Claude Code.
- **Secrets.** Never open, print or copy `.env` files (`.env.example` is fine), keys or tokens.
- **Commits.** Use the git identity already set in the repo; never change git config. Add no AI co-author or "generated by" trailers. Use small Conventional Commits (`feat(web): …`, `style(web): …`, `fix(web): …`). Name any new dependency and its licence, and say why it's needed, in the commit message.
- **Paid things.** Ask the founder before using anything paid: UI kits, templates, stock photos, font licences, hosted animation or 3D services.

## This machine
Rocky Linux 8. Node is used only through `pnpm exec` and `pnpm run` (there's no global `node`/`npx`). Next.js builds with `--webpack`, because the system glibc is too old for Turbopack; the `make` targets already handle both. Run the app with `make dev` (it needs Docker), then open http://localhost:3000. `make seed` loads fictional sample PGs.

## Before you call a chunk of work done
Run `make lint-web typecheck-web test-web` in your tree and fix what fails. Then check every page you changed:
- at 360 px, 768 px and 1440 px wide;
- in light and dark mode;
- with the keyboard alone;
- with reduced motion turned on.

The full browser tests (`make e2e`) and Lighthouse budgets run in Claude Code's review.
